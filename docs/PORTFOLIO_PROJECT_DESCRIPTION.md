## 2. 60-Second Overview

>
> It operates across three core modules:
> 1. **Research Assistant:** Multi-source ingestion with socket-level DNS SSRF validation, resilient 4-tier scraping, and epistemic claim categorization.
> 2. **Writing Assistant:** 6 deterministic Python heuristics calculating Flesch Readability and applying surgical, non-destructive sentence-level edits while preserving immutable source copy.
> 3. **Editorial Studio:** 300–500-word structured drafting with traceable numbered citations `[1]`, `[2]` and multi-format exports.

> The stack pairs React 18 and TypeScript with an asynchronous FastAPI backend, SQLAlchemy 2.0 connection pooling, multi-stage Docker containerization running as non-root `appuser`, and an offline deterministic fallback that guarantees zero downtime."*
